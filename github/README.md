# Tachistoscop v0.1

Aplicație Android offline care simulează un tahistoscop mecanic.

## Ideea de bază
- Aparatul este afișat ca o carcasă de lemn cu fereastră închisă.
- Textul este ascuns înainte de expunere.
- Tragi mânerul vertical pentru a tensiona mecanismul.
- La eliberare, clapeta se deschide și se închide automat.
- O tragere mai puternică produce o expunere mai scurtă.
- Nu există sunete, reclame, cont, internet sau AI.

## Conținut
În Setări poți folosi:
1. **Un element pe linie** — cuvinte, cifre, sintagme sau orice combinație.
2. **Text în blocuri** — lipești un text și alegi între 1 și 6 cuvinte pe expunere.

Trecerea între elemente este manuală prin butoanele Înapoi / Următorul.

## Font
Poți regla:
- Serif
- Sans
- Monospace
- Serif cursiv
- Mărimea între 22 și 72 sp
